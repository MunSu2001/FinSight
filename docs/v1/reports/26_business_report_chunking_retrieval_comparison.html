26. 사업보고서 청킹 A/B와 근거 검색 비교

저장된 노트북 출력 확인: 2026-10-05 · 삼성전자·리노공업의 2024 사업연도 사업보고서 각 1건 · 개발 질문 10개

목적: 25번에서 선택한 B 추출 텍스트를 같은 검색기로 찾을 때, 제목 경계를 먼저 분리하는 것이 근거 청크의 검색 순위에 영향을 주는지 확인한다. 청킹 외 조건은 고정하며, 검색기 자체의 우열이나 최종 답변 품질은 평가하지 않는다.
간단한 결과·결정: 두 후보 모두 정답 인용문 10/10개가 청크에 남았다. 제목 경계 우선 B는 A보다 Hit@5가 9/10 대 8/10, MRR@5가 0.745 대 0.483으로 높았다. B를 다음 검색 비교의 조건부 청킹 기준선으로 사용한다. A는 현재 기준선으로 미채택하되, 다른 검색기·문서·질문에서도 B가 우세하다는 최종 결론은 보류한다.

정답 사례는 삼성전자 5개, 리노공업 5개다. 같은 문서·접수번호에 속한 개발 질문이므로 독립 holdout이나 실제 사용자 질문 분포가 아니다. 검색은 기업이 이미 식별됐다는 조건에서 해당 기업 문서 안에서만 수행한다.

4. 채택·미채택과 한계

후보현재 결정이유와 남은 조건
A. 전체 청킹다음 비교의 기본값으로 미채택이번 어휘 검색 기준선에서 B보다 낮은 Hit@3/5·MRR@5. 다만 단순 구조의 비교 기준선으로 보존한다.
B. 제목 경계 우선조건부 기준선이번 10개 개발 질문에서 평균 검색 순위가 좋고 정답 문구 보존도 동일했다. 시설투자 실패와 종속기업 순위 악화는 해결하지 못했다.
최종 확정 보류: 2개 기업의 사업보고서 2건·10개 개발 질문만 평가했고, 정답은 원문 인용문 하나씩으로 정의했다. 파라프레이즈 근거, 여러 청크를 합쳐야 하는 질문, 다년도·다기업 문서 검색, 최종 답변 정확도는 포함하지 않았다. 이 결과를 임베딩·하이브리드 검색이나 실제 운영 사용자 질문으로 일반화하지 않는다.

다음 실험은 B를 고정하고 어휘·dense vector·hybrid retrieval을 같은 근거 질문과 사용자형 재표현 질문에서 비교한다. 이후 검색 방식을 고정하고 B와 parent–child 청킹을 비교한다. 사용자형 재표현이 기존 인용문을 재사용한다면 독립 정답으로 합산하지 않고 따로 보고해야 한다.
