21. LangChain Tool Calling Prompt 비교

실행일: 2026-09-21 · 기준 모델: gpt-5.6-luna · 개발 평가 17문항 · 온도 0 · reasoning effort none

결론: 상세 정책 Prompt B를 다음 Tool 실행·기간 Resolver 평가의 조건부 기준선으로 채택한다.
B는 A보다 Tool F1, 완전한 Tool 집합 일치, 계약 인자 일치, 유효 계획률에서 모두 높고 Invalid-plan Rate가 낮았다. 다만 이 17문항은 개발 세트이며, KB금융처럼 금융업 제외를 지키지 못한 사례가 있다. 따라서 B를 최종 운영 Prompt나 통합 workflow로 확정하지 않는다.

1. 이 테스트의 목적

사용자 질문을 실제 OpenDART 호출 전에 필요한 작업 요청으로 바꾸는 LangChain bind_tools() 단계의 품질을 비교했다. LLM이 함수명·설명·입력 스키마를 받은 뒤 반환한 tool_calls만 평가했으며, Tool 함수와 OpenDART API는 실행하지 않았다.

따라서 이 결과는 “무엇을 호출해야 하는가”의 품질이며, 데이터 조회 정확도·계산 정확도·RAG 검색 품질·최종 답변 품질을 뜻하지 않는다.

6. 한계와 다음 판단

  • 17개 개발 질문 한 번의 비교이므로 B의 일반화 성능이나 운영 안정성을 보장하지 않는다.
  • 사업보고서 주제·공시 키워드의 의미적 적합성은 이 평가의 Exact Match 대상이 아니다. 해당 품질은 실제 공시/RAG 평가에서 측정한다.
  • 실제 Tool 실행·OpenDART 응답·기간 가용성·CFS/OFS 대체·계산·최종 답변은 아직 검증하지 않았다.
  • Router-only 비교를 추가로 세분화하지 않는다. B를 임시 기준선으로 두고 실제 Tool 실행·기간 Resolver 평가를 진행한 뒤, 변경된 구조 전체를 독립 holdout에서 재확인한다.
