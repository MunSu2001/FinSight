# FinSight 도메인 용어 정리

FinSight 전체에서 자주 나오는 재무·공시·Agent 용어를 짧게 정리한 문서다. 이 문서는 투자 조언이나 지표의 좋고 나쁨을 판단하는 기준이 아니라, **데이터가 무엇을 뜻하는지** 이해하기 위한 기준이다.

## 1. OpenDART와 공시

| 용어 | 설명 | FinSight에서의 사용 |
|---|---|---|
| DART | 금융감독원의 전자공시시스템이다. 기업이 제출한 공시를 조회할 수 있다. | 재무제표와 사업보고서 원문의 출처다. |
| OpenDART | DART 데이터를 프로그램으로 조회할 수 있게 제공하는 Open API다. | 현재 V1의 유일한 외부 데이터 원천이며, 이후 Tool의 데이터 원천 중 하나다. |
| 공시 | 기업이 법정·자율 의무에 따라 외부에 공개하는 정보다. | 기간별 공시 목록과 원문 링크를 제공한다. |
| 사업보고서 | 회사의 연간 사업 내용, 재무제표, 위험요인 등을 담은 정기 공시다. | V1 재무 데이터의 기본 보고서이자 RAG 원문 범위다. |
| 사업연도 | 회사가 재무 성과를 정리하는 회계 기간이다. 보통 1년이지만 기업마다 종료일이 다를 수 있다. | 다기업 비교 시 연도뿐 아니라 결산일도 함께 표시한다. |
| 결산월 (`acc_mt`) | 기업의 사업연도가 끝나는 달이다. | 같은 2024년이라도 기간 종료일이 다른 기업을 구분한다. |
| `reprt_code` | OpenDART에서 보고서 종류를 지정하는 코드다. `11011`은 사업보고서다. | 현재 V1 재무 조회는 기본적으로 `11011`만 사용한다. |
| `corp_code` | OpenDART가 공시 대상 회사에 부여한 8자리 고유번호다. | 기업명으로 찾은 뒤 모든 OpenDART 조회의 기본 식별자로 사용한다. |
| `stock_code` | 상장회사의 6자리 종목코드다. | 상장 상태를 표시하고 이후 시장 데이터 확장 시 기업 연결 후보로 사용한다. 비상장 기업은 비어 있을 수 있다. |
| `corp_cls` | OpenDART 기업개황의 법인 구분이다. 유가증권(Y), 코스닥(K), 코넥스(N), 기타(E)로 표시된다. | 상장 상태를 설명하는 원천 필드다. V1은 이를 비상장 기업 제외 기준으로 사용하지 않는다. |
| `induty_code` | OpenDART 기업개황이 제공하는 업종코드다. | 금융·비금융 판정의 원천 정보다. 한국표준산업분류와의 실제 매핑은 별도 확인한다. |
| `rcept_no` | 공시가 접수된 14자리 접수번호다. | 원문 링크, 재현 가능한 근거, RAG 문서 식별에 사용한다. |
| 최종 제출본 | 정정 공시 등이 있으면 최종적으로 유효한 제출본을 뜻한다. | 기간 공시 목록과 원문 근거에서 어떤 문서를 사용했는지 명확히 남긴다. |

## 2. 재무제표 구조

| 용어 | 설명 | FinSight에서의 사용 |
|---|---|---|
| 재무제표 | 기업의 재무 상태·성과·현금흐름을 정해진 형식으로 정리한 표다. | V1의 원천 수치가 나오는 기본 데이터다. |
| 연결재무제표 (CFS) | 모회사와 자회사를 하나의 기업집단으로 합쳐 작성한 재무제표다. | 일반적인 기업집단 분석을 위해 우선 사용한다. |
| 별도재무제표 (OFS) | 모회사 한 곳의 재무 상태와 성과를 따로 작성한 재무제표다. | CFS가 없을 때만 대체 사용하고, 결과에 별도 기준이라고 표시한다. |
| CFS/OFS 혼합 | 같은 비교 안에 연결 기준과 별도 기준이 함께 있는 상태다. | 조회는 가능하지만 규모·비율 비교가 제한될 수 있으므로 기준과 주의사항을 표시한다. |
| 재무상태표 (BS) | 특정 시점의 자산·부채·자본을 보여 주는 재무제표다. | 자산총계, 부채총계, 자본총계, 유동자산, 유동부채를 가져온다. |
| 손익계산서 (IS) | 일정 기간의 수익·비용·이익을 보여 주는 재무제표다. | 매출액, 영업이익, 당기순이익을 가져온다. |
| 포괄손익계산서 (CIS) | 손익계산서 항목과 기타포괄손익을 함께 보여 주는 형식이다. | 기업이 IS 대신 CIS 형식으로 제출해도 손익 계정을 찾을 수 있도록 확인한다. |
| 현금흐름표 (CF) | 일정 기간 실제 현금의 유입·유출을 영업·투자·재무 활동으로 나눠 보여 주는 표다. | 영업활동현금흐름을 가져온다. |
| `sj_div` | OpenDART 응답에서 재무제표 종류를 나타내는 값이다. 예: BS, IS, CIS, CF. | 각 항목을 올바른 재무제표에서만 찾는 필터다. |
| XBRL | 재무 공시를 컴퓨터가 읽을 수 있게 구조화한 표준 형식이다. | OpenDART raw 계정의 ID·명칭을 이용해 반복 가능한 매핑을 만든다. |
| `account_id` | XBRL 계정의 식별자다. | 계정명보다 우선해 매출·자산 등 원천 항목을 매핑한다. |
| `account_nm` | 사람이 읽는 계정명이다. | `account_id`가 없거나 기업별 표현이 다를 때 보조적으로 확인한다. |
| `thstrm_amount` | OpenDART 응답의 당기 금액 필드다. | 선택된 원천 계정의 실제 금액으로 사용한다. |
| 통화 (`currency`) | 금액이 표시된 통화다. | 원천 통화·단위를 남기고, 답변에서 읽기 쉬운 단위로 변환했으면 기준을 표시한다. |

## 3. 현재 OpenDART 리서치의 원천 재무 항목

| 용어 | 설명 | FinSight에서의 사용 |
|---|---|---|
| 매출액 | 기업이 상품·서비스를 판매해 얻은 수익 규모다. | 성장성·수익성 계산의 기준값이다. |
| 영업이익 | 주된 영업 활동에서 비용을 제외하고 남은 이익이다. | 영업이익률 계산과 본업 수익성 흐름 확인에 사용한다. |
| 당기순이익 | 일정 기간의 최종 이익 또는 손실이다. | 순이익률, ROA, ROE 계산에 사용한다. |
| 자산총계 | 기업이 보유하거나 통제하는 경제적 자원의 총액이다. | ROA 계산에 사용한다. |
| 부채총계 | 미래에 상환·이행해야 할 의무의 총액이다. | 부채비율 계산에 사용한다. |
| 자본총계 | 자산에서 부채를 뺀 순자산에 해당하는 금액이다. | 부채비율과 ROE 계산에 사용한다. |
| 유동자산 | 통상 1년 안에 현금화되거나 사용될 자산이다. | 유동비율 계산에 사용한다. |
| 유동부채 | 통상 1년 안에 상환할 부채다. | 유동비율 계산에 사용한다. |
| 영업활동현금흐름 | 주된 영업 활동에서 발생한 현금흐름이다. | 영업현금흐름률 계산과 이익·현금흐름의 차이 확인에 사용한다. |

## 4. 현재 OpenDART 리서치의 계산 지표

| 용어 | 설명 | FinSight에서의 사용 |
|---|---|---|
| 매출 성장률 | 전년 대비 매출이 얼마나 변했는지 나타내는 비율이다. `((당기 매출 / 전기 매출) - 1) × 100` | 다년도 성장 흐름을 보여 준다. |
| 영업이익률 | 매출 중 영업이익이 차지하는 비율이다. `(영업이익 / 매출) × 100` | 본업 수익성 흐름을 확인한다. |
| 순이익률 | 매출 중 당기순이익이 차지하는 비율이다. `(당기순이익 / 매출) × 100` | 최종 수익성 흐름을 확인한다. |
| ROA | 평균 자산을 활용해 낸 당기순이익의 비율이다. `(당기순이익 / 평균 자산총계) × 100` | 자산 대비 수익성 참고 지표다. |
| ROE | 평균 자본을 활용해 낸 당기순이익의 비율이다. `(당기순이익 / 평균 자본총계) × 100` | 자본 대비 수익성 참고 지표다. |
| 부채비율 | 자본 대비 부채의 비율이다. `(부채총계 / 자본총계) × 100` | 재무구조를 참고하는 지표다. |
| 유동비율 | 유동부채 대비 유동자산의 비율이다. `(유동자산 / 유동부채) × 100` | 단기 유동성을 참고하는 지표다. |
| 영업현금흐름률 | 매출 대비 영업활동현금흐름의 비율이다. `(영업활동현금흐름 / 매출) × 100` | 이익과 현금흐름을 함께 볼 때 사용하는 프로젝트 정의 지표다. |

> 주의: 비율은 분모가 0이거나 음수이면 해석이 왜곡될 수 있다. FinSight는 이 경우 숫자를 억지로 계산하지 않고 계산 불가 또는 비교 주의로 표시한다. 서로 다른 업종의 비율을 비교할 때도 우열이나 투자 적합성을 단정하지 않는다.

## 5. FinSight Agent workflow 용어

| 용어 | 설명 | FinSight에서의 사용 |
|---|---|---|
| 원천 수치 | OpenDART에서 직접 가져온 계정 금액이다. | LLM이 만들지 않으며 답변의 숫자 근거가 된다. |
| 정규화 | 기업별 raw 계정 행을 V1의 공통 항목명과 구조로 정리하는 과정이다. | 다기업·다년도 표를 만들기 전에 수행한다. |
| 결정론적 계산 | 같은 입력이면 항상 같은 결과가 나오는 코드 기반 계산이다. | 성장률·마진·비율 계산을 LLM 대신 처리한다. |
| 결측 | 요청한 기업·연도·계정에 데이터가 없거나 매핑하지 못한 상태다. | `None`으로 남기고 추정하지 않는다. |
| 공통 사업연도 | 다기업 비교에서 모든 대상 기업의 기준 데이터를 확보할 수 있는 같은 사업연도다. | 서로 다른 최신 연도를 섞어 비교하는 오류를 막는다. |
| Tool | 특정 데이터 조회·계산·검색을 수행하는 함수 단위다. | 기업 식별, 재무 조회, 계산, 공시 목록, RAG가 각각 Tool 후보가 된다. |
| Router | 질문을 구조화해 필요한 Tool과 인자를 선택하는 구성요소다. | 이후 Prompt·Tool 설명 후보를 비교 평가한다. |
| RAG | 문서에서 관련 근거를 검색해 LLM 답변에 제공하는 방식이다. | 사업보고서의 위험요인·사업환경 등 정성 근거가 필요한 경우에만 사용한다. |
| Evidence Packet | 수치, 계산식, 공시 메타데이터, 문서 근거를 한 답변 단위로 묶은 구조다. | LLM이 근거 밖의 내용을 만들지 않도록 답변 입력으로 사용한다. |
| Validator | 근거 누락, 수치 불일치, 인용 오류를 확인하는 구성요소다. | 후보 방식의 품질을 평가한 뒤 필요할 때 workflow에 넣는다. |
