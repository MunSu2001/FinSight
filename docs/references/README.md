# FinSight 레퍼런스

이 폴더는 FinSight의 설계·평가·구현 판단에 재사용할 수 있는 **외부 근거**를 분류해 둔 지식 인덱스다. 사람이 읽는 참고자료이면서, Codex와 검토 에이전트가 새 단계의 설계 또는 평가를 시작하기 전에 필요한 범위만 확인하는 근거 문서다.

레퍼런스는 프로젝트 요구사항이나 실제 실행 결과를 대체하지 않는다. 사용자와 합의한 범위·정책은 `docs/v1/` 같은 계획 문서에, 용어의 짧은 정의는 `docs/DOMAIN_GLOSSARY.md`에 둔다.

## 분류

| 폴더 | 담는 자료 | 현재 상태 |
|---|---|---|
| `technical/` | 공식 API·프레임워크·모델 연동 문서 | OpenDART·LangChain·ChatOllama 자료 등록 |
| `domain/` | 공시·재무제표·기업 리서치 도메인 사실과 1차 출처 | OpenDART·IFRS의 CFS/OFS 근거 등록 |
| `product/` | 사용자, 업무 흐름, 문제 정의, 경쟁/시장 조사 근거 | 실제 제품 설계 단계에 수집 |
| `ui/` | 승인된 화면 참고 이미지, 출처, 채택 이유 | UI 설계 단계에 수집 |

## 등록 규칙

- 외부 사실은 출처 URL, 확인일, FinSight에서의 활용 목적을 함께 기록한다.
- 출처로 확인되지 않은 해석·아이디어는 레퍼런스의 사실처럼 적지 않는다. 프로젝트 정책이면 해당 계획·요구사항 문서에 분리한다.
- 새 기술·도메인·UI·제품 판단이 필요해지면, 먼저 필요한 하위 폴더의 자료를 조사해 추가한다.
- 에이전트는 필요한 하위 폴더만 읽는다. 이 폴더 전체를 자동으로 모두 읽지 않는다.

## 기존 V1 문서와의 관계

`docs/v1/REFERENCES.md`는 V1 실험을 시작하며 기록한 단계별 기술·API 근거다. 이 폴더는 V1 이후에도 재사용할 수 있도록 출처를 주제별로 관리하는 상위 인덱스다. 동일 출처를 다시 해석하거나 결과를 복제하지 않고, 필요하면 기존 V1 문서를 연결해 사용한다.
