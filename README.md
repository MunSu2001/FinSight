# FinSight

**국내 상장사 리서치 과정을 근거와 함께 자동화하는 AI Research Agent**

FinSight는 투자 판단을 대신하거나 종목을 추천하는 서비스가 아닙니다. 사용자가 기업을 조사할 때 반복하는 재무 조회, 공시 확인, 수치 계산, 근거 정리를 하나의 재현 가능한 리서치 흐름으로 연결하는 것을 목표로 합니다.

## 프로젝트 목적

국내 상장사 분석에는 정형 재무정보, 공시 원문, 시장 데이터처럼 성격이 다른 자료를 함께 확인해야 합니다. FinSight는 자연어 질문을 조사 작업으로 분해하고, 필요한 데이터와 계산을 선택한 뒤, 출처와 실행 과정을 포함한 리서치 결과를 제공합니다.

```text
질문
→ 조사 계획
→ 재무·공시·시장 데이터 조회
→ 결정적 계산
→ 근거 검증
→ 출처가 연결된 리서치 메모
```

## 대상 사용자

주요 대상은 국내 상장사 분석 보고서를 직접 작성하거나 검증하는 투자 스터디 구성원과 기업 분석을 시작하는 개인 리서처입니다.

이들은 DART, 증권 정보 사이트와 공시 원문을 오가며 자료를 찾고, 기간별 수치를 맞추고, 계산과 출처 정리를 반복합니다. FinSight는 이 첫 조사 과정을 줄이되, 사용자가 결과와 근거를 직접 확인할 수 있게 합니다.

주니어 리서처와 기업 전략·IR 담당자의 경쟁사 조사 지원은 장기 확장 대상이며, 초기 MVP의 주사용자로 가정하지 않습니다.

## 차별성

### Evidence-first

답변 자체보다 근거를 우선합니다. 재무 수치는 OpenDART 재무제표, 공시 내용은 원문 문서, 시장 수치는 해당 시세 제공처로 분리해 출처를 남깁니다.

### Research workflow

범용 LLM처럼 바로 요약을 생성하는 대신, 질문에 필요한 작업을 조회·검색·계산·검증으로 나누어 수행합니다. 사용자는 어떤 데이터를 어떤 순서로 사용했는지 확인할 수 있습니다.

### 검증 가능한 관찰

공시일 전후 주가 변화처럼 서로 다른 데이터를 날짜 기준으로 연결할 수 있습니다. 다만 관찰된 변화와 공시 사이의 인과관계는 단정하지 않습니다.

## 제품 경계

- 매수·매도·목표주가·개인화된 투자 추천을 제공하지 않습니다.
- 공시와 주가 변화의 인과관계를 근거 없이 주장하지 않습니다.
- 근거가 없거나 Tool 실행이 실패한 경우에는 이를 결과에 명시하고, 검증 가능한 범위만 답합니다.
- 금융·법률 규제에 대한 최종 적합성은 공개 서비스 이전에 별도 검토가 필요합니다. 현재는 미검증입니다.

## 최종 기능 방향

초기 제품은 단일 기업의 최근 재무 추세, 주요 공시와 원문 근거, 결정적 재무 계산, 출처·실행 경로가 포함된 리서치 결과를 다룹니다.

이후 시장 데이터가 추가되면 공시일 전후의 가격·거래량 변화를 사실로 정리할 수 있습니다. 최종적으로는 질문을 분해하는 Coordinator, 재무·공시·시장 조사 역할, 근거 Validator, 결과 Synthesizer가 구조화된 근거를 주고받는 multi-agent workflow를 검증합니다.

```text
Research Coordinator
  ├─ Financial Research
  ├─ Disclosure Research
  ├─ Market Context Research
  ├─ Calculator
  └─ Evidence Validator
          ↓
   Research Synthesizer
```

모든 역할을 항상 실행하지는 않습니다. 질문에 필요한 역할만 선택하고, 각 역할은 자유 형식의 대화 대신 출처·날짜·수치가 포함된 구조화된 근거를 반환하는 것을 목표로 합니다.

## 예시 질문

> 삼성전자의 최근 3년 매출과 영업이익률 변화를 정리하고, 같은 기간 확인할 주요 공시 근거를 알려줘.

> 특정 공시일 전후 5거래일 동안의 주가와 거래량 변화를 보여주고, 인근 시점의 공시를 함께 정리해줘.

두 번째 질문은 향후 시장 데이터 연동 범위입니다. 결과는 관찰 사실을 제공하며 주가 변동 원인을 단정하지 않습니다.

## 기술 방향

- **OpenDART**: 기업 고유번호, 재무제표, 공시 목록과 공시 원문
- **Python**: 데이터 조회, 정규화와 결정적 계산
- **LangChain**: LLM, Prompt, Structured Output, Tool 인터페이스
- **LangGraph**: 상태 기반 조사 workflow, 분기, 검증과 재시도
- **LlamaIndex**: 사업보고서·공시 원문 검색을 위한 RAG
- **시장 데이터 API**: 향후 시세·거래량 분석에 사용할 별도 데이터 원천

OpenDART는 공시 검색, 기업 고유번호, 공시 원본 파일 등 기업 리서치에 필요한 API를 제공합니다. [OpenDART 개발 가이드](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS001) 시장 데이터 제공처는 구현 전 인증 방식, 이용 조건과 데이터 범위를 별도로 검증합니다.

## 현재 상태

현재는 최종 pipeline 구현 전 학습·검증 단계입니다. OpenDART 재무 조회, LangChain의 Structured Output·Tool Calling, LangGraph의 State·Node·Edge·조건 분기, 실제 OpenDART workflow, OpenDART 근거 기반 LLM 답변 생성을 notebook으로 확인했습니다.

학습 노트북의 역할은 [notebooks/learning/README.md](notebooks/learning/README.md)에서 확인할 수 있습니다. 통합 Agent, RAG, 시장 데이터, multi-agent workflow, API 서버와 대시보드는 아직 구현하지 않았습니다.

## 시작하기

1. [OpenDART](https://opendart.fss.or.kr/)에서 API 인증키를 발급받습니다.
2. `.env_example`을 참고해 프로젝트 루트에 `.env`를 만듭니다.
3. 실제 인증키를 입력합니다.

```env
OPENDART_API_KEY=발급받은_API_KEY
```

4. `notebooks/learning/`의 학습 노트북을 번호 순서대로 실행합니다.

`.env`는 Git 추적 대상에서 제외되며 실제 API 키를 저장소에 커밋하지 않습니다.
