# FinSight

OpenDART의 기업 공시와 재무데이터를 활용해 근거 기반 기업 분석을 수행하는 AI Agent 프로젝트입니다.

FinSight는 단순한 재무정보 조회를 넘어, 사용자의 질문을 여러 작업으로 나누고 필요한 데이터와 공시 근거를 찾아 하나의 분석 결과로 연결하는 것을 목표로 합니다.

## 프로젝트 소개

기업을 분석하려면 정형 재무데이터와 비정형 공시문서를 함께 살펴봐야 합니다. 여러 기업과 사업연도를 비교하려면 데이터를 반복해서 조회하고, 필요한 지표를 계산하고, 사업보고서에서 관련 근거를 찾아야 합니다.

FinSight는 이 과정을 하나의 분석 흐름으로 연결합니다. 사용자의 요청을 해석한 뒤 재무정보 조회, 수치 계산, 공시 검색과 근거 검증에 필요한 기능을 선택하고 조합합니다.

```text
사용자 질문
→ 요청 분석과 작업 분해
→ OpenDART 재무정보 조회
→ 수치 계산
→ 공시문서 검색
→ 결과 통합과 근거 검증
→ 필요 시 재검색 또는 재실행
→ 최종 기업 분석
```

FinSight가 처리하고자 하는 질문의 예시는 다음과 같습니다.

> 삼성전자와 SK하이닉스의 최근 3년 매출과 영업이익률 변화를 비교하고, 각 기업의 사업보고서에서 주요 위험요인을 찾아 실적 변화와 함께 분석해줘.

## 해결하려는 문제

- OpenDART 데이터와 공시문서를 각각 찾아봐야 하는 번거로움
- 기업마다 다른 재무계정과 공시 구조를 직접 해석해야 하는 문제
- 기업 간·기간별 비교를 위해 조회와 계산을 반복해야 하는 문제
- 생성된 분석이 어떤 데이터와 공시 내용에 근거하는지 확인하기 어려운 문제

## 목표 기능

- 기업명과 사업연도를 기준으로 주요 재무정보 조회
- 여러 기업의 매출, 영업이익과 재무비율 비교
- 사업보고서와 공시문서에서 질문과 관련된 근거 검색
- 재무데이터와 공시 근거를 결합한 분석
- 분석에 사용한 데이터, 문서와 실행 과정 확인
- 근거가 부족하거나 도구 실행이 실패한 경우 재검색 또는 재실행

## 분석 흐름

```text
사용자 질문
→ 요청 분석과 작업 분해
→ 재무정보 조회 / 수치 계산 / 공시 검색
→ 결과 통합
→ 근거 검증
→ 필요 시 재검색 또는 재실행
→ 최종 기업 분석
```

## 기술 구성

- **OpenDART**: 기업정보, 재무제표와 공시문서의 원천 데이터
- **Python**: 데이터 수집, 가공과 분석 기능
- **LangChain**: LLM과 분석 도구를 연결하는 인터페이스
- **LangGraph**: 상태를 기반으로 여러 분석 단계를 제어하는 workflow
- **LlamaIndex**: 사업보고서와 공시문서 검색을 위한 RAG 구성

LangChain, LangGraph와 LlamaIndex는 현재 구현된 기능이 아니라 앞으로 검증할 기술 방향입니다.

## 현재 개발 상태

현재는 OpenDART API와 데이터 구조를 이해하는 초기 단계입니다. Python 표준 라이브러리로 기업명에서 `corp_code`를 찾고, 해당 기업의 전체 재무제표 raw JSON과 주요 재무항목을 확인하는 실험을 진행하고 있습니다.

실험 코드는 [`notebooks/01_dart_api.ipynb`](notebooks/01_dart_api.ipynb)에서 확인할 수 있습니다. 아직 Agent workflow, RAG, API 서버와 대시보드는 구현하지 않았습니다.

## 데이터 출처

OpenDART의 [기업 고유번호 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018)와 [단일회사 전체 재무제표 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)를 사용합니다.

## 시작하기

1. [OpenDART](https://opendart.fss.or.kr/)에서 API 인증키를 발급받습니다.
2. `.env_example`을 참고해 프로젝트 루트에 `.env`를 만듭니다.
3. 실제 인증키를 다음 형식으로 입력합니다.

```env
OPENDART_API_KEY=발급받은_API_KEY
```

4. `notebooks/01_dart_api.ipynb`의 셀을 위에서부터 하나씩 실행하며 ZIP, XML, JSON과 주요 필드를 확인합니다.

`.env`는 Git 추적 대상에서 제외되며 실제 API 키를 저장소에 커밋하지 않습니다.
